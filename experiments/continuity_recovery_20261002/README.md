# Verified historical fact recovery

`continuity.py` adds a receiver-owned class-center-free invariant and strictly
overlapping raw-ray backfill. `MODEL_ADDENDUM.md` records the age/future
acceleration correction. `PROTOCOL.md` was frozen before measurement;
`READING.md` records actual primary-paper reading scope, not full reproduction.
`THEORY.md` derives conditional recovery and its limits.

On sheng, six initialized archived histories × target25/39 × four methods ×
three randomized repeats give 144 calls. Fixed and shortened greedy each recover
geometry in 6/12 targets, but neither passes any of its 36 timed requests.
This is a fixed-region retrospective experiment, not a new CARLA drive.

From repository root with Python, NumPy/SciPy and a compiled cover dependency:

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
export MOBI_COVER_LIBRARY="$PWD/build/incremental_validity_20261002/cover.so"
export PYTHONPATH="$PWD/experiments/continuity_recovery_20261002"
python -m unittest discover -s experiments/continuity_recovery_20261002 -v
python experiments/continuity_recovery_20261002/bench.py --capture results/online_evidence_20261002/live --out /tmp/mobi-new-continuity-study
python experiments/continuity_recovery_20261002/analyze.py --results results/continuity_recovery_20261002 --capture results/online_evidence_20261002/live --out /tmp/mobi-continuity-audit.json
```

Build the dependency as described in `incremental_validity_20261002/README.md`.
The first command creating a study output refuses an existing directory. The
audit command targets the complete archived study/build layout. Independent
ungrouped ball queries check all required cells, original selected raw sources,
the entire corrected initial history, temporal intervals and all-row arithmetic.
Only first-repeat packet bytes are archived; other repetitions have measured
rows and arithmetic checks. Original history setup is separately measured.
No process, scheduled research loop or automation is launched by the audit.

For causal maintenance, bounded lossless transport and native complete geometry,
see the finite follow-up `../streaming_recovery_20261002/README.md`.
