# 从不完整观测求证据有效期：可验证的有限结论

## 目标与不能省略的前提

目标不是预测“道路会空多久”，而是回答：在与已收到的射线、已验证且尚未过期的历史、误差和障碍运动上界相容的世界中，指定区域至少还能保持外部障碍不相交多久？传感器不透明核心、外接半径、误差、时钟、速度/加速度的上界都属于前提；本实验没有证明这些前提对真实道路成立。

仅有未检出目标、没有这些约束时，观测相同的两个世界可以分别有空道路和立即侵入的遮挡目标。因此不能同时给出无条件可靠、严格为正且不保守的有效期。学习置信度不能自行排除第二个世界。若改用统计约束，必须明确覆盖事件、目标分布和适应性；既有独立回合校准不支持本次自适应闭环的条件风险。

## 与现有验证器一致的最长有效期

当前实现只处理固定的已验证矩形区域，未来动作占据必须另外完整包含于其中。对障碍类别 c：

- U_c 是在完整有限网格中，当前射线及合法历史均未排除的单元中心。所有未观测单元保留在 U_c 中。
- d_c 是 U_c 到矩形的最小距离；q_c = step_c / sqrt(2)。这是一种保守网格模型中的边界，不是真实连续未知空间的精确边界。
- m 为区域位姿余量，r_c 为障碍外接半径，δ_c 为时钟余量。
- b_c(h) = m + r_c + v_c(h+δ_c) + a_c(h+δ_c)^2/2。

既有 `body.coverage` 的固定区域判定等价于：

    d_c > b_c(h) + q_c

并且矩形每一轴最大绝对坐标加 b_c(h) 严格小于建模域半径。两条不等式必须对每一类别都成立。其原因是：射线/历史排除集合不依赖所查询的未来 h，而所需覆盖区域随 h 单调扩张；失败恰好发生在第一个尚未排除单元进入所需区域或越出有限建模域。

因此先计算一次完整排除集合，再对整数微秒 h 二分，得到 H*：在给定上限内通过同一个网格证书的最大 h。若连 1 微秒都无法通过，则返回 0。算法保存限制类别和最近未排除单元作为可检查的失败证据。到达上限时必须标记上限截断，不能称为无界有效。

这消除了固定 400 ms 选择和按 50/100 ms 搜索的额外保守性，但不消除网格、外接形状、运动上界和观测误差本身的保守性，也不声称新颖性。数值实现与已有浮点几何验证器一致，没有新增经过机器验证的区间算术证明。

## 通信、计算与动作必须消耗同一时钟

证据到期点是 E_us = reference_us + H*_us。当前到达时刻应向上编码为 A_us。若完整动作与有限备份的时长上界为 T_us，必要的时间条件是：

    A_us + T_us < E_us

同时必须满足整段动作占据包含条件。计算新边界也有成本，不能在离线计算后把它当成零延迟在线输出；观察到的运行时间不等于未来最坏时延。消息丢失或等待不会重置 E_us。

历史续期另需 next_reference_us < parent_expiry_us。本次旧启动测试用浮点 `now + .05 < expires`，而接收端使用整数参考时间；不到 1 微秒的表面余量让启动成功但下一帧父证据已到期。`root_ready` 使用与编码一致的整数比较，拒绝这种启动。它是预计下一帧时间的预检，真正续期仍须检查实际采样时间，不能代替实际检查。

## 明确证据层次

全量射线的 H* 是离线观测信息能力诊断；原始射线数可能超过线上包上限，不能直接当作可发送证书。已发送射线子集的 H* 才可在不增加射线的情况下重编码，且每个非零结果重新经过原完整验证器。

如果全量射线边界很长、子集边界很短，问题在压缩或选择；若两者都短，不能用更快编码制造不存在的几何信息；若边界足够但动作剩余时间不足，问题在端到端时延/动作接口。本次代码按这三个层次报告，不把离线潜在空间、已传输证书和实际执行混成一个成功率。
