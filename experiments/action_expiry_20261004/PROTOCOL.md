# Finite action-query interface verification

This is a deterministic geometry/interface extension, not a new learned model,
fresh statistical qualification or closed-loop driving result. Do not inherit the
previous fixed-query selective certificate for arbitrary queries or an ego policy.
No new CARLA capture, controller search or recurring job is scheduled by this step.

Compile the frozen supported pose/circle sets or fallback body/pose sets once per
source frame. Accept arbitrary planar integer-micrometer disk centers and radii,
declared nonnegative target speed/acceleration, and a cap no greater than500ms.
Compute the greatest integer age satisfying strict separation. Keep the original
source epoch on every repeated query. A disk may enclose a declared ego swept body;
its construction, localization error and realized actuator behavior require their
own validation and are not provided by a state-set certificate.

For supported evidence, exact circle/rotated-rectangle intersection nonemptiness
must hold before a positive proposal. For fallback, a finite rational witness
search must find a point in the body-ball union AND pose-rectangle union. Each
witness is exactly checked; unresolved feasibility refuses, not falsely empties.
Distances use exact downward rounding and the maximum of two component-set lower
bounds. Existing sources and historical reports stay frozen.

Freeze all implementation/tests/probe/audit sources and dependencies before any
data replay. Seven boundary tests cover strict maximality by integer enumeration,
source-age expiry, empty/disjoint/multimodal sets, contract validation, radius/motion
monotonicity and the non-transferable certification gate.

Replay all2046 captured source frames of the published independent test, now used
only as a deterministic implementation regression fixture. For each of two
component families, compare the two original query proposals; preserve every
new refusal/decrease and disagreement. Check14 additional fixed disk queries:
x=-9,-6,-3,0,3,6,9m, y=2m, radii0.75/2.5m. Ground truth only checks geometric
membership/lower-bound/oracle implications offline; it never enters Evidence.
No performance, generalization or new risk certification follows from reuse.

An independent auditor recomputes exact circle/rectangle geometry and separation
using Fraction and exhaustive maximality boundaries. For score-covered source
frames it checks containment and that every reported lower distance is below the
true-center distance. Source-age proposals must not exceed the declared true-center
oracle. Geometry-eligible queries remain deployment_authorized=False.

Run tests and the finite replay on sheng, then compare local independently generated
audit bytes. Publish all sources, case-level outputs, refusals, regression counts,
tests and audit hashes. Failed checks are retained; no test-driven statistical
retuning or replacement episodes. Full project remains incomplete until actual
ego/communication/policy-distribution evidence and the remaining scope are verified.
