# 从部分观测到可用有效期：保留信息、补齐缺口、支付时延

## 可信性的边界

如果允许遮挡区出现任意大小、速度和位置的障碍，同一组观测可以对应立即碰撞或完全空旷的世界。仅凭未检出目标，不能推导无条件、严格为正的有效期。本项目使用可检查的条件证书：每个障碍类别的不透明核心、外接半径、运动界、射线/位姿误差、时钟界和合法历史都明确给定。真实传感器及道路是否满足这些界，仍须独立验证。

射线只证明其误差界内的穿越位置不能被该类障碍的不透明核心占据。射线年龄逐条计入误差；未知单元始终可能含有障碍。历史只能来自接收端完整验证且在新参考时刻严格未过期的证书，旧消息模板只提供选取当前射线的索引建议。模板本身不提供自由空间。

## 避免额外的有效期保守性

沿用 [固定区域最长有效期推导](../expiry_frontier_20261001/THEORY.md)：对类别 c，令 U_c 为当前射线及合法历史未排除的网格中心，d_c 为 U_c 到固定矩形的最近距离，q_c = step_c / sqrt(2)。设区域位姿余量为 m，障碍外接半径为 r_c，时钟余量为 δ_c，则同一网格验证器的条件是

    d_c > m + r_c + v_c(h + δ_c) + a_c(h + δ_c)^2 / 2 + q_c

同时必须满足有限建模域的严格包含条件。所有类别取交集，以整数微秒二分求最大的通过值 H*，并报告限制类别、最近未排除单元及上限截断。固定区域代码拒绝非零平移、转动和加速度；动作的完整占据需要另行检查。

这里的“最大”只是在既有保守网格证书与给定上限中的最大值，不能称为连续物理世界的真实最大安全时长。它消除固定 400ms 和粗粒度搜索的额外损失，保留模型本身的保守性。前缀搜索复用同一判定，不放松未知区域。全量射线的 H* 是观测能力诊断；可发送子集的 H* 才是消息所携带的信息能力，前者不能免费用于线上决策。

## 本次算法：只为尚未排除的必需单元补证

在目标期限 h 下，类别 c 的必需单元集合为 Q_c(h)。当前模板建议的基础射线 B 与合法历史 P 已覆盖其中一部分。定义

    G_c = Q_c(h) \ (Cover_c(B) ∪ Cover_c(P))

每个候选当前射线 i 都重新计算对应类别的误差 e_ic。它排除一个单元中心 x 的充分条件是

    ||x - w_i|| < r_min,c - e_ic - step_c / sqrt(2) - 1e-9

右侧不为正时不能排除任何单元。按真实误差分箱，对 G_c 查询具有可用半径的射线；任何缺口无法排除时拒绝。最近有效射线的并集给出一个覆盖所有缺口的候选集合 C。候选集上的既有精确贪心只需覆盖各类别缺口的带类别索引并集，而不重建基础区域。添加 A 后，B ∪ A 仍覆盖所有 Q_c(h)。原因是每个必需单元或者已由 B/P 排除，或者属于 G_c 并被 A 排除。基础射线不删除，因此不会损坏原有覆盖。

这是条件充分性论证，不是全局最少字节优化：C 是最近有效射线的候选子集，贪心只对 C 的离散集合覆盖工作；不声称对所有当前射线的全局最优或对其最优解的近似比。保留 B 也可能增加消息量。包上限、整数期限和全接收端重算仍不变。旧 4/16 邻居方案、新最近有效补证和新缺口贪心均使用相同的编译版完整覆盖回退，并支付失败尝试的成本。

## 有效信息不等于到达后可用信息

到期点 E_us = reference_us + sent_horizon_us。采集、生成、完整接收端验证和链路都会消耗证据时间。诊断计算

    R = sent_horizon - acquisition - generation - verification - wire

再将上述总年龄向上取整到 50ms tick，并保留 200ms 动作时长，严格检查

    tick_age_us + 200000 < sent_horizon_us

还需要原接收端在该到达时刻接受消息。200ms 是既有受限回合研究的组件界；本次没有验证新策略的动作占据、有效车辆响应或物理最坏界。计时通过只能叫回放中的时间预算通过。

## 对公平比较和因果解释的限制

共同投影优化只复用与障碍类别无关的射线几何区间，再逐类别加入运动误差，保持原浮点运算顺序和向上误差分箱。三个发送方案及共同回退都得到该优化，原接收端保持不变。优化前后包必须字节相同，因此它改变成本而不改变信息与几何有效期。它属于实现成本控制，不单独构成算法新颖性。

两阶段分别使用六个事后选取的旧状态，以及十次旧闭环记录中的全部 384 个输入。每个方法都使用旧闭环实际接收历史，而非自身产生的反事实历史；当前 packet 只能在克隆接收端中检查。这是配对回放，不能推导新闭环轨迹、实际行驶改善、无线性能、未来 WCET 或分布外可靠性。不同时间的优化前后计时也不是随机化同时对照；方法内顺序随机/轮换不消除跨运行负载变化。
