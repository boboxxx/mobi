# Finite receiver-recomputable raw-ray proof study

This stage follows the heterogeneous error audit. Existing geometry and ray-time results are known. It is not an externally preregistered study. It updates the communication interface without claiming a new theory of set cover or reachability.

The receiver fixes every required obstacle profile, error contract, episode/frame/query/plane scope and action horizon. The packet contains quantized selected first-return endpoints, sensor origins, individual observation times and a common evidence reference time. The receiver recomputes crossing eligibility, projection error, quantization error and per-ray motion debit. No sender-supplied scalar uncertainty is accepted. A checksum detects accidental corruption only; source authenticity, trustworthy first returns and physical bounds remain external prerequisites.

Use existing twelve first-frame CARLA clouds, two stipulated obstacle classes, 0.1 m vehicle grid, 0.05 m small-core grid, and 200 ms requested validity. Compare heterogeneous joint greedy cover to a uniform-threshold cover with identical inputs; uniform thresholds are searched until a sufficient cover exists, without using obstacle labels. Add a matched compressed complete-ray representation for byte accounting only, not a SOTA learned baseline.

Production input boxes: 0.002 and 0.01 m componentwise point/origin/query error. Main scans are simultaneous, matching CARLA measurement semantics. Also evaluate 20/50 ms azimuth-assigned rolling timing with end phase zero, the previously informative phase; this is explicitly a selected diagnostic, not a new blind phase study or measured rolling sensor experiment. Preserve all failures.

For each condition that produces a template, renew on later stored free/near/far scans from the same sensor configuration. Both algorithms must use current rays. Record serialized bytes, fresh-ray provenance, receiver recomputation, expired-packet refusals, and measured processing plus explicitly modeled 20 ms transport and 50 ms action. Cold-start and renewal costs remain separate. Large complete-frame compressed bytes are a same-data accounting baseline, not a wireless measurement.

This stage does not certify an entire vehicle trajectory: the protected action occupancy remains a declared 0.5 m disk. Dynamic full-vehicle control is a separate uncompleted integration requirement. No recurring job is created.
