# Post-analysis finite transport extension

The initial 7560 measured rows remain frozen. After observing that0.5Mbps
serialization dominates, run the SAME seven methods, six histories, twenty
frames, three repeats and three presets again: another7560 rows. Same physical
model, source generation services, mathematical frontier, warm roots and paid
FIFO timing. Method order seed20261008 is unchanged. No baseline receives an
extra observation, free checkpoint, free ACK or more permissive action gate.

Each sender tracks at most4 exact normalized raw templates. A full message
sends the previous self-contained typed dictionary. Send a full refresh every
five indices20,25,30,35 and whenever normalized geometry/relative ages/physical
metadata change. Otherwise send the template SHA, immutable packet header and
new ref/horizon/seq/original checksum. Receiver stores a template only after
the full packet passes the original typed source, time/order and scope checks.
A reference requires that receiver-owned template; absent/corrupt/out-of-order
templates fail closed. There is no acknowledgement. Loss of a full message can
prevent reference decoding until a subsequent refresh; this cost is tested
as a negative unit case, NOT repaired with out-of-band oracle information.

Sender normalization/hash/encoding are measured. Receiver reference expansion,
typed packet reconstruction/reencoding, original decoder and all mathematics
are measured together; nothing is declared free because it was compressed.
The initial template and periodic refresh pay actual full bytes. Blackout
indices27–29 happen not to remove a refresh in these frozen presets; results
are not a claim of resilience to arbitrary reference dependency loss.

Store outputs in dictionary_study. The separate independent audit reconstructs
raw bytes from its OWN receiver template history, rejects any unreceived full
template dependency, fully verifies all7560 costs and378 coverage intervals,
and uses the same independently derived KD/endpoint checks. No candidate codec
or flow module is imported. New test_dictionary.py targets missing templates,
wrong-checksum, future/replay, changed geometry, refresh and decompression caps.
This is an established transport optimization applied to repeated saved
geometry. It neither proves novel semantic coding nor generalizes the previous
positive counts to moving scenes/real wireless/useful driving.
