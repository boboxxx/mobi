# 固定执行边界准入开发批次

先冻结全部代码/输入并提交，再运行12项计划；失败保留、不补抽、不调参重跑。相同三类行人运动、两个位置与history/snapshot交替顺序，沿用原部分XYZ、登记体积、速度5m/s与模量3|dt|+.15契约。源状态与两策略报文相同，history用已发布的等价CAP早停，snapshot为同一强径向基线；不使用事后四次求根优化。Audi A2默认物理/手动一挡，反馈目标.5m/s、域上限.75m/s；x=-8→+3中心路线，30s尝试+1.5s制动尾段。绝不关闭物理或覆盖速度。源每100ms，控制/执行检查每50ms。

本批是明确的**虚拟事件时钟协同仿真**：每回合时钟0对应记录的真实CARLA起始frame，之后每physics tick增加恰50,000µs。sensor原始实际timestamp另存，允许与逻辑clock有微秒数值差异并核对。一个回合内源epoch永不重置；episode身份隔离，不能接收另一回合旧lease。唯一时钟驱动器在输入应用前后核对world.frame不变，再推进一个物理tick。

源感知可用延迟**模型**固定50ms，另支付实际测得的copy+encode CPU时间；CPU FIFO与20Mbps/20ms源无线FIFO分别推进。50ms是本批选择的场景参数，**不是对真实sensor延迟的保证**。旧批用render调用walltime收费，本批模型不同，因此不能将新旧差值归因为单个算法改动。日志/归档、render/world.tick和CARLA控制RPC属于模拟平台开销，单独保存耗时，不再把它们伪装为会推进本批physics clock的计算延迟。

接收decoder CPU FIFO从真实的模型packet arrival起排队，完成之前不可用。它是只依赖已产生packet/context的纯运算，可以在推进事件时重建先前完成时刻；不能使用未来world状态。控制查询以本tick本车状态和已完成decoder的最新源状态为输入，实际测得proposal+编码CPU费用排队；返回lease经第二条20Mbps/20ms FIFO。执行侧解码同样付款，未完成解码的lease不能应用。每个job的到达、开始/结束、报文和费用均可独立重建，任何费用增大只会推迟可用。

模拟执行侧每tick以当前本车位置重验：身份/源epoch/动作300ms截止/空间包含。空间余量为 `2.5m−本体登记三维球半径−.75m/s×.3s−.02m`，检查本车当前中心到lease查询中心的真实欧氏距离。源区域/时限不能因新指令或新缓存扩大。无有效lease时全制动；过期/未到达是瞬时拒绝，不触发整回合永久拒绝。物理速度域违反、碰撞或指定道路域离开仍永久拒绝。每个已许可go最多保持50ms；无后续有效许可则执行后备全制动，要求250ms内连续三采样低速≤.02m/s。因此300ms覆盖50ms保持与250ms后备确认。已有末端/随机单次制动研究**不移植成此闭环的制动证书**；本批所有完整制动段另外核对，重启前的中断段明确单列。

执行检查与physics输入应用在逻辑tick边界视为**原子模拟执行器**。实际CARLA RPC耗时记录，但world不推进，因此它不构成本批物理输入迟延。此处没有实现真实Windows/CARLA native watchdog，也不声称wall-clock20Hz、硬件WCET或实测无线。真实硬件部署需要原生执行端检查/独立制动保障，不能从这里推导。

逐源/报文/全回合保存原始回波、真值审计、immutable epoch、队列、指令与实际控制、失败/cleanup。独立analyze重建CPU/无线FIFO、最新可用状态/lease、空间/时间门控与策略，再核对源中心/状态、全回合碰撞、速度模量、本车全动作采样包络、目标采样分离、制动确认和路线。真值不进入决策。仅12固定开发回合，没有IID或5%风险认证，也没有连续时间物理契约证明。道路清空完成率与占道停车分开；不把停车当路线成功。

条件推导：若源状态/运动契约覆盖真实目标，执行检查确为原子边界，本车连续速度界与后备确认契约成立，则空间包含与绝对epoch截止足以覆盖每次50ms go和失去后续证据时的250ms后备段。过期后的驻车若被其他目标撞击，不由有限源前缀证明排除；完整回合事件照样计入。传感契约、动作契约与执行时钟三者不可互相替代。

本批预期检验部分观测历史在完整路线中是否比同信息snapshot减少保守停车，允许结果为零或反例。历史状态估计、分离证明、执行端截止/后备控制均已有近邻；不因组合这些工具宣称新理论。只创建本批有限实验，不创建持续研究循环。原旧结果与失败完全保持。
