# 从不完整观测推导有效期：集合后验与表示误差

本阶段把旧的固定中心区域连续覆盖条件，与既有的集合成员估计基线比较。
目标是辨别拒绝来自真实信息不足，还是证明规则/表示的过度保守。集合预测、
观测交集、遮挡可达集和距离变换均是既有方法，不作为本项目的原创理论。
相关原始论文、阅读范围与复现差异见 `READING.md`。

## 物理前提及证据语义

对每类障碍，所有可能成员在每个实际选中观测时刻满足给定速度上界 v、
加速度上界 a、内含不透明球半径 r_min、外包半径 r_max。首回波射线、
量化/投影/位姿误差、参考坐标及公共时间轴可信。对象连续存在，不允许
在被排除的内部区域任意生成新对象。未建模区域保持未知，不把缺少回波
解释为空区域。SHA256 验证一致性，不提供传感器真实性。

这些是条件模型，尚未经完整物理标定。尤其不能把每帧给定的 v 误读成
只有初始时刻给定的 v。若选中最新实际射线到参考时刻间隔为 d，则参考
速度为 v_ref=v+a*d；未来 h 位移采用 v_ref*h+a*h²/2，而每条射线的
投影误差仍使用自己的年龄。删除非平面最新时间戳会改变合同，故保留。
原始传输合同不变；细化仅改变接收端内部网格。

## 保守后验归纳

设 P_k 为参考时刻 t_k 的可能障碍中心集合的网格外包。可信旧根完全
重验后，其已证明区域的所有完整 tiles 可标为空；其它 tiles 为可能。
根的实际射线也可排除完整 tiles。无需自行假定自遮挡内部为空。

给定 Δ=t_k−t_(k−1)>0，最大位移

    D_k=(v+a*d_(k−1))*Δ + a*Δ²/2.

预测集合包含距离旧可能 tiles 不超过 D_k 的 tiles，以及从有限域外
可能进入的边界 tiles。随后只去掉被当前实际射线证明整体为空的 tiles。

    P_k = outer_grid(Reach(P_(k−1), D_k) ∪ ExteriorArrivals(D_k)) \ E_k.

若真实中心包含于上一步集合，则连续轨迹的当前中心必在预测集合中。
正确的全 tile 空证据不能去掉真实中心。于是归纳得到每一步集合都包含
真实中心，且旧行动授权过期后，新的真实观测仍能使后验重新收缩。这与
恢复过期行动权限不同：只有新后验、新参考时刻和新期限满足收件/执行
门槛时才可接受。不能凭重放旧根或保留发送方的 horizon 字段恢复权限。

## 对齐 tile 的距离计算

等宽、轴对齐的闭合 square tiles，每轴最小间距是两个区间端点间距，
重叠则为零。对于相同格网上的两个 tiles，最近点可在各自顶点中选到。
因此 tile 到旧可能 tile 并集的最小距离，等于四个目标顶点到旧可能
tile 顶点并集最近距离的最小值。实现用欧氏距离变换；独立审计用顶点
KD 树，并在小格网上与直接两两 box 距离核对。不在每次传播额外添加
随意的 tile 半径；但保留外包取整带来的真实保守性及向外 1e−9 m 比较。

当前射线为空球的半径使用原始 r_min 减原始射线误差。tile 中心距球心
小于该半径−step/√2−1e−9 时才删除整个 tile；投影、年龄和误差完全重算。
细化不会把原始传感误差或物体半径缩小。

## 有效期边界

设 R(h) 为给定 motion/clock 下车体的保守占据包络，M(h) 包含位姿误差、
r_max 和障碍未来位移。接收端检查每类可能中心 tiles 与 R(h)⊕M(h)
不相交，并检查需求在计算域内部。当前实验 motion 为固定车体；算法的
最大整数微秒 H 是此后验和此充分检验支持的最大值，不是所有真实世界
解释中的最优安全期，也不是移动控制系统已实现的安全期。

实现以最近可能 tile 中心到车体包络距离，并减 tile 半对角线做检验；
单调二分得到 H。独立审计枚举所有需要 tiles，在 H 通过、H+1 拒绝。
H=0 时仅确认 H=1 不能证明；这不证明真实障碍必然存在。

证据时限必须同时满足（严格）：

    向上取整的证据年龄 + 200000 μs < H.

年龄支付实际原始采集、已测 FIFO 源生成、当前装包/压缩、解压/整个
后验重建/边界计算，以及 20 ms+实际字节×8/20 Mbps，按 50 ms 向上取整。
旧根初始化单独报告。不同重复的计时不能冒充硬实时最坏界。

## 本阶段改变了什么结论

原来 6 个严格时间断链目标不能据此判定信息本身不足。固定 K 与粗网格
集合观察器均支持 6/12；在同原始输入/同物理参数下，一次预定 factor2
细化支持 10/12，其中 4 个恢复目标来自原先断链组。这是表示精度影响
拒绝的反证。两个仍失败目标也未获连续轨迹反例或联合位置/速度最优
滤波证明，故不能称为不可辨识。

细化后全部请求仍过时。可信性、空间表示精度与使用前成本必须联合
考虑；延长发送字段或离线免费计算边界都不能解决实时性。后续可研究
保守计算窗口、精确历史表示/传输、增量后验，但必须把同样优化给强
基线并验证未知入口、原始重建及全部成本。当前结果不构成 MobiCom
创新或完成驾驶闭环的声明。
