# 预注册：动态不完整回波的位置—速度关联诊断

这是固定的开发诊断，不是校准集、独立风险认证或完整驾驶实验。以前冻结的文件不改。方法属于集合观察器与支持函数的直接参考实现，**不以此组合宣称原创**。

## 假设与所证明的条件性质

已登记 walker.pedestrian.0001，单目标存在；CARLA Town10HD_Opt 原固定 RSU、场景坐标和背景。运行时只读 XYZ、传感器外参、登记体积和原始采集时刻，不用目标 ID、标签、真实位置、速度或运动控制。当前组件/yaw 外包集合经精确有理数转换成轴向中心区间。全部历史观测区间覆盖真实中心、平面速度不超过5m/s、每轴加速度绝对值不超过3m/s²时，源位置—速度真实状态属于推断多边形。该前提并非由模型或数据自动保证。

每轴变量(p,v)保留最近至多7个观测，历史时间差d的约束是 L−Ad²/2 ≤ p−dv ≤ U+Ad²/2。没有组件、空几何集合或任一缺失历史均拒绝。中心集合包含未知 yaw 的所有可行单组件假设，再作轴向外包；不硬选一个方向/组件。运动必须独立满足边界。

未来 min_vertex sign(p+tv−q)−R−At²/2 为凹函数。一个固定轴/方向的首末严格正间距足以证明连续整个源前缀分离。输出最大**充分证明**前缀，500ms上限；不是最大真实安全期限。查询球2.5m（包含动作/执行的既定几何包络），目标球为登记三维半径。允许条件是原始源年龄+已支付费用+300ms动作 ≤ 前缀。重新计算不得续源。

## 固定对照与费用

1. joint：历史约束的二维(p,v)多边形；
2. factorized：相同历史、相同多边形的p/v边界，拆成独立矩形（强时序对照）；
3. snapshot：仅当前观测及相同5m/s、3m/s²范围。

三者同原始点云/源频率/未知姿态前提/半径/查询/时间上限。报文均传轴向观测历史（相同信息与字节）；序列化实测。观测前端与三种推断/两次查询总源计算开销用同一保守共同费用，另加实测采集费、20Mbps串行化和20ms传播。这是收费的离线反事实查询，**不是实测无线或实时闭环**。接收端直接使用编译好的前缀；共同源费涵盖查询求解，额外20ms执行费。开始用证据的源年龄至少100ms；无计算时钟替代源时刻。

捕获前的解析检查发现：所有历史条带都是 p−dv 约束且d≥0，故最小p与最小v可同时达到，最大p与最大v亦可同时达到。对于任意未来t≥0，joint和factorized的轴向支持函数相同；两者前缀应逐项完全一致。150组精确有理数历史的单元测试支持此等式。**预期关联方案无独立收益**，不以相同结果包装创新；物理批次主要检验历史与snapshot的可用性差别及覆盖前提是否满足。

## 固定物理开发批次

24个不同场景：4运动（停留、+x远离、−x靠近、+y横穿）×3参考x偏移(−1,0,+1)m×2y偏移(−0.4,+0.4)m。运动恒定控制1.2m/s（停留0）；控制先运行1s暖机，暖机不作为可信历史。再收集60步20Hz、每2步发送，30源/场景，预计720源。查询(−6,0)、(−4,0)m配对，覆盖近/远间距。生成计划/源hash后再启动捕获。固定ClearNoon、256通道/35m/2Mpps/20Hz语义LiDAR，保留每4条回波；其ID/标签只进审计。目标存在且已知类，此批没有未知目标/不存在目标/路线到达。

所有失败场景/漏覆/域违反保留，不补抽、不改本批参数。真值每50ms只作审计：观测中心覆盖、推断(p,v)覆盖、速度/差分加速度界、声明前缀内查询球与目标球分离。采样检查不能证明连续真实动力学边界。末尾缺少未来审计范围的许可标为censored，不记成功。整数前缀精确算法有独立数学单元测试；统计结果按场景配对报告，帧不当IID证书样本。只有24回合，不授予5%风险认证。
