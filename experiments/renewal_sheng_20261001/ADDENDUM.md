# Post-run reference supplement

The initial 38,500-episode run is preserved. Inspection found that the six-step rolling finite-horizon reference can idle indefinitely in the deterministic two-region case: both immediate start and delayed start yield four rewards within six steps, while delayed start needs five rather than six transmissions. Replanning repeatedly selects delay. Exhaustive enumeration confirms this is the implemented finite-horizon objective's end effect, not a recursion error. It is not evidence that a shorter algorithm beats the general optimum.

Before running the supplement, add a generic infinite-horizon discounted (gamma 0.99) value-iteration reference for the same small model, converged to Bellman residual below 1e-10. Immediate expected reward breaks near-equal ties, followed by idle and stable action order. Run 11 configurations × 500 seeds = 5,500 additional episodes on sheng with the same exogenous outcome tables. This is a post-diagnostic analysis, not the initial frozen protocol. Stationary optimization still assumes the current required set stays fixed; it cannot see future requirement changes or realized losses.

The CARLA gate uses two fixed roadside sensor mounts, 20 measured frames in each free/occupied condition, after 20 warm-up frames. The primary grid is 0.5 m, with a 1 m resolution sensitivity and deterministic 8-fold thinning. These settings are fixed before its measurements. A passing discrete-ground-coverage test does not prove continuous empty volume; a failing test blocks promotion of that representation to a driving certificate.
