# 事后连续前缀算法单元，不替换原闭环策略

问题：同一固定分离方向的前缀，是否因方向不能随时间变化而保守？在已固定源p/v区间盒上，未来中心外包为各轴[p_lo+t*v_lo,p_hi+t*v_hi]加欧氏球 `rho(t)=.15t+1.5t²`（SI）。本体加查询球的半径为R。对查询点到未来矩形的**真实距离**，检查 `distance(t)>R+rho(t)` 的完整连续前缀。

各轴距离分支在盒边穿过查询坐标时变化，至多四个内部断点。每段距离平方减膨胀半径平方是有理系数四次多项式。Sturm根计数核对全区间，包括不变号的触碰根；整数二分找首次失败之前最大的微秒。不能只看终点、控制采样或多项式浮点根。结果对声明的外包模型是最大连续前缀，不宣称对原始部分观测、完整运动可行集或任意物理轨迹全局最优。

严格反例：p=(-1.25,3.77)m，v=(5,0)m/s，R=3.5m。整个500ms动态管道分离；端点膨胀球凸包却包含原点，因此**任何单一固定法向**都无法证明全窗口。不靠方向网格调密回避这个缺口。

实现/有意义测试先固定，再回放已公开的closed_loop_motion_20261011观测。数据已被看过，明确为事后算法诊断，非盲测、非风险认证、不产生新驾驶成功率。依然保留原全局5m/s径向证明，输出二者较长前缀；若原等价快实现已500ms封顶，直接返回，因为任何改进都不可能超封顶。所有有缓存的6905行逐一比较原整数前缀，新值不得减小；报告改善数、费用、300ms/20ms原费用下的影子门控差异，不移植成改变后的路线结果。无未来真值入推断，不改变原物理记录/失败处理。

连续碰撞检测及Sturm根计数均为已有工具。本单元验证它们是否消除本项目固定法向的额外保守性，不能宣称首次发明CCD、Sturm或时间变化分离面。原RPC费用长尾、执行端截止和制动/独立校准问题仍另外解决。
