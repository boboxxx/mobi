# Separately frozen sender/receiver information diagnostic

Use all36 ORIGINAL sphere witnesses. Inspect only the full CURRENT saved scan
at the same target observation time, never a future scan. Select one previously
untransmitted, error-bounded plane-crossing ray whose core-exclusion margin at
the witness's reference-time center is maximal. Include original componentwise
endpoint/origin boxes, quantization, XY query registration, actual ray age and
upward error bin. Archive the extra typed one-ray fact and source/cloud hashes.

The fact disproves this particular candidate trajectory. It does NOT prove
that all hidden trajectories are absent, grant any action, establish a longer
TTL or demonstrate an online optimal communication policy. Full scan reads and
ray selection costs are measured separately; no actual transmission is run.
The former upper bound remains valid for the ORIGINAL receiver information;
the new fact changes that information, so the former witness must be rechecked.

An independent checker reconstructs the exact encoded ray from original XYZ
and pose, checks actual timestamps and omission from the received dictionary,
and evaluates64 pairs of endpoint/origin box corners. Coordinate extrema give
a conservative planar crossing box. Add query allowance and numerical padding;
compare every possible crossing with the candidate core at that ray timestamp.
Do not call the selection/projection/native/witness search implementation.
