## 部署方案（未执行）

1. 核查 Windows 是否已有可复用的 CARLA；若无，在 D:\CARLA 下解压官方 Windows 预编译包。先锁定稳定版本，例如 0.9.15，并建立独立的匹配版本客户端环境。现有客户端带开发提交后缀，不能直接假定它与发行包完全匹配。无需从源码构建 Unreal Engine。
2. 首次从 Windows 登录会话启动，确认地图可加载和 GPU 正常工作。基础命令为 `CarlaUE4.exe -carla-rpc-port=2000`。随后测试 `-RenderOffScreen -nosound` 的无窗口运行，保留传感器渲染；记录实际启动参数。
3. WSL 客户端连接当次 Windows 网关地址，而非默认使用 localhost。当前为 `carla.Client('172.18.160.1', 2000)`。核对客户端/服务端版本、地图、传感器输出。若防火墙阻断，仅对所需 WSL 来源放行相关端口，不开放公网访问。
4. 一个进程负责 world.tick，使用同步模式和固定 0.05 秒步长。若背景车辆使用 Traffic Manager，同步设置其同步模式。物理子步长例如 0.01 秒、最多 10 步。相机等传感器按 frame ID 对齐，不能假定刚收到的数据就是当前帧。
5. 验证退出时恢复世界设置、销毁本次 actors，并保留逐帧日志，避免后续实验继承状态。

`no_rendering_mode=True` 会使相机等 GPU 传感器返回空数据，不能将其作为保留视觉感知的加速开关。Low 画质也会改变可见距离；正式比较应固定画质和传感器配置，不能为了提速引入新的可见性差异。

## 最小闭环

Windows CARLA 物理世界 → WSL 传感器感知 → 语义消息构造/选择 → 限带宽、延迟和丢包队列 → 自车融合与规划 → 油门/制动/转向 → CARLA 下一帧。

先搭建一个受遮挡路口：一辆自车、两个协作视角（车辆或 RSU）、遮挡物及横向来车。初期用 LiDAR 构建 occupied/free/unknown 三态证据，保留统一规划器和控制器，降低大型视觉模型的工程负担。空闲证据来自实际观测覆盖和射线，不把“未检测到目标”直接解释为安全。

自车规划不得通过 simulator actor 列表获得未观测车辆的位置。地图和自车定位可以作为显式公共输入；全局真值仅用于生成场景、独立评估和清楚标记的 oracle 对照。Traffic Manager 可以控制背景交通，不应用其全局信息替代被测自车规划。

通信层维护真实序列化字节数、发送队列、服务速率、发送/到达时间、丢包和过期条件。请求、反馈及其他必要控制报文计入成本。接收端只能读取已到达的消息，所有方法使用同一到达机制和决策截止时间。不要先把邻车全部观测送给接收端，再在接收端假装选择待传信息。

## 仿真闭环和墙钟实时性分开验收

- 第一阶段：可复现的同步闭环。0.05 秒是模拟时间步长，不代表一个循环真的只用 50 ms。记录真实计算耗时；若采用理想零计算延迟，仅作为明确标注的算法上界。
- 第二阶段：加入采集、感知、编码、选择、传输、融合和规划的时间。按产生时刻和可用时刻调度结果，模拟时间不能因计算暂停而让信息免费保持新鲜。晚到结果应丢弃或留待下一决策，期间执行上一控制或规定的保守策略。
- 第三阶段：同机端到端运行，测实时因子 RTF=模拟时长/墙钟时长、循环耗时 P50/P95/P99、截止时间违约率、显存及传感器丢帧。20 Hz 的周期为 50 ms；平均 RTF≥1 仍不足以证明满足尾延迟要求。

先跑单次 60 秒模拟、再连续运行 10 分钟，测量随协作视角、传感器数和感知模型规模变化的性能。以上为计划，不是实测结果。4090 同时承担渲染和推理，两者会争用 GPU；不能预先保证任意传感器配置都达到 20 Hz。

## 科研验收

同一感知、消息表示、规划器和通信预算下比较：无通信、周期广播、强单步 VoI（允许停止和冗余删除）、组合选择、小规模集合最优及完整信息参考。先确认充分的邻车信息确实能改变动作，再测组合选择相对单步的余量。

必须加入表示消融：对象框与 free/occupied/unknown 证据分别使用相同选择器，分清“表示提供了新信息”和“组合选择发现了互补”的贡献。

覆盖双向遮挡、单一危险源、无遮挡、过期证据等条件；设置机制诊断场景，也报告自然混合场景中的发生率。以场景/episode 为统计单元，配对随机种子，保留独立测试地图或布局。

同时报告碰撞、近失事件、成功通行率、通行时间、停车等待、有效吞吐及消息时效。停车不动可以降低碰撞，所以必须联合评价安全与进展。若集合最优依旧贴近强单步，则当前组合选择假设仍不成立；闭环平台本身不能替代创新证据。
