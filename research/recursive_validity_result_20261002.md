# 不完整观测中的证据有效期：先约束一致世界，再计算可用时间

当前能给出的是**物理模型条件下、接收端可重算的有效期**。本轮已经在
sheng 完成两组各7,560行有限实验；两组在本地与sheng的独立审计JSON
分别逐字节一致。不能把静态回放中的数学正确性写成真实道路安全，
也不能把已知集合估计、运动约束或字典复用写成新的 MobiCom 理论。

用户问题的准确数学对象是：给定截至当前已收到且已验证的观测 E、物理
边界 Θ 和具体行动 π，构造所有与它们一致的隐藏对象连续轨迹集合 Ω。
令 T_bad(x,π) 为某条一致轨迹首次与车辆行动占用包络冲突的时间，则

    H* = inf_{x∈Ω(E,Θ)} T_bad(x,π) − reference_time

只讨论参考时刻后首次危险；初始已无法证明安全时不给授权。如果未来
物体永不可能进入行动包络，H* 可以无穷，但实现仍受有限计算域和搜索
上限约束。这个定义把“可信”解释为覆盖所有符合条件的隐藏世界，把
“不过度保守”解释为尽量接近同一信息、同一模型下的 H*，而不是随意
降低置信要求或者与弱基线比较。当前网格后验只是 Ω 的外包络，输出
有效期是保守下界；并未证明信息论最优，也未量化与真实 H* 的全部差距。
定义要求模型与数据一致；不能把一致世界空集解释成无限安全。实现
尚未提供完整物理模型违约监测器，这也是部署可信性未成立的原因。

如果物理边界只以统计方式成立，需要对**整段部署中、含自适应取样的
联合边界事件 G**建立覆盖概率。只有证明 P(G)≥1−δ，条件性几何证明
才能推出错误授权概率≤δ。单次预测的平均精度、模型置信分数、校验和
或若干测试零失败，都不能替代这一步。本轮未完成传感器、遮挡内核、
所有潜在入侵者运动以及公共时钟的联合校准。

## 本轮消除的两类不必要保守性

接收端逐帧维护已验证事实，避免每次请求从旧根重算整段历史；但事实
保存不等于行动授权保存。新的行动证书只能在验证完成后使用，并严格
满足 now+200ms<expiry。收到一个过于宽松、有效期0的后验不会凭空撤销
同一区域内仍有效的旧证书；已过期的旧授权也不会被历史回放恢复。

第二处来自过去运动传播。原模型已经假设**每个实际观测时刻，所有该类
成员，包括没有看到的成员，都满足速度上界**，并且持续满足加速度范数
上界。旧传播却只使用起点约束。新观测到达并验证后，两端约束共同给出

    |v(s)| ≤ min(V0+a·s, V1+a·(Δ−s)), 0≤s≤Δ
    D_past ≤ ∫ min(V0+a·s, V1+a·(Δ−s)) ds

V0、V1 都包括最新实际射线相对参考时间的年龄修正。等端点时得到
VΔ+aΔ²/4，旧式是 VΔ+aΔ²/2。以 V=5m/s、a=3m/s²、Δ=500ms 为例，
2.875m 收紧为2.6875m，低于旧475ms证书及其20ms时钟余量已经排除的
约2.8425m范围。因而旧**自由区域事实**可以过渡到新参考时间，再用当前
射线完整检查新的外圈。550ms间隔仍超过该预算，在这些输入上失效。

这个修正同时给固定区域强基线和粗/细位置集合方法。未来有效期仍用
V1(h+clock)+a(h+clock)²/2；绝不偷用尚未收到的下一帧终点约束。
对象必须具有连续持久轨迹，所有潜在入侵者在可信根时刻就已存在；若
只约束已检测对象或允许任意新生对象，上述证明不适用。计算窗口外
始终 UNKNOWN，每次传播都允许未知对象从边界进入。

## 发现低带宽失败后直接完成的传输修复

第一组冻结不改。再冻结一个公平的跨帧字典对照，共另7,560行。所有
方法缓存同样的已验证几何模板，每五帧发完整刷新，变化几何立即发全包；
否则发送模板SHA、当前参考时间/序号/原始校验和和不可变类型头。
接收端必须实际收到合法模板，引用再完整重建原射线并经原解码器核验。
首次模板、周期刷新、发送端归一化/散列、接收端展开/重编码均付出成本，

新增4项测试在两台主机通过，包括首字典丢失后引用拒绝、坏模板不得

失去模板依赖时会失效；失去几何证据的历史也不会被完整字典凭空恢复。
第二组独立审计在两台主机通过且逐字节一致：与第一组相同的252/120来源、8,208逻辑传播、
327独立KD算子、2,784掩码、2,253边界、7,560费用及378覆盖率检查，另逐帧
从审计器自身实际接收的模板历史重建原始包，未导入被测字典代码。

306/360次单帧通过仍然只覆盖约15%的观察时间。覆盖率计算的是证书
实际可用时刻至 expiry−200ms 的区间并集；观察区间固定为第20帧参考时刻
至第39帧后500ms，包括此前已合法接受的根证书剩余授权。这不是持续
有效驾驶。根前缀验证为7方法合计20.743–21.764s，单独记录；回放使用
已经接受的热根，不冒充实时冷启动。源生成服务沿用原实测记录，新的
编码与接收端核验实测，三段FIFO排队/序列化显式计费；后台日志、归档
及实验框架管理不是生产系统服务基准，不能将本结果当成WCET。

标准条件下，固定两端基线在原 reference_fixed、c2/reference_rate20
两组从9/60、6/60提高到各60/60；最困难的 reference_rate20仍只有6/60。
细网格旧有“恢复四个目标”的优势在强两端基线下消失。不能再声称精细
后验比固定区域基线有独有科学收益。小幅时延/覆盖差异不是统计显著
优势，本报告不据此宣称优于所有控制或估计方法。

## 与论文的关系及候选问题修正

本轮直接阅读的[IEEE TWC waypoint语义通信正文](https://arxiv.org/html/2312.13182v2)
将AoI/VoI用于命令排序，目标是轨迹MSE，并在指定部分忽略处理耗时。
本项目要证明隐藏世界中的行动有效期，指标和验证对象不同；该差异
本身不构成创新。[2026年semantic push-pull预印本](https://arxiv.org/html/2609.21566v1)
已使用预测创新及其年龄衰减决定通信，所以“预测置信驱动通信”并非
空白。[RSS2021遮挡博弈论文](https://www.roboticsproceedings.org/rss17/p066.pdf)
进一步考虑未来可观测后的响应，提示单纯避免所有未来可达集可能仍然
过保守。本轮阅读章节、失败获取记录和推断界限见 `READING.md`。

候选问题应定位为：**部分观测、延迟和丢包下，接收端如何从已验证的
历史重建行动相关的有效期，并在计算/通信成本下维持可用授权区间？**
已完成的部分包括条件性过去传播证明、事实/授权分离、强匹配基线与
有限测量。仍缺可信物理边界、变化几何、行动/备份占用包络的实际执行、
无线竞争及独立部署泛化。MobiCom候选的创新尚未成立；本轮发现应收缩
旧主张而不是继续给相同技术换名字。全项目不标记完成，不创建持续循环。
