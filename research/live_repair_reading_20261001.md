# 局部续期修复的相关工作增量核查

检索与阅读时间：2026-10-01。本记录服务于新闭环实验的贡献边界，没有声称完成系统综述。

- [Engineering Algorithms for Dynamic Greedy Set Cover，2026 v1](https://arxiv.org/html/2604.03152v1)：阅读引言、§2 与 §3 开头。它比较四类动态贪心实现，考虑覆盖大小、更新时间与解的变化量；其基本模型保持集合族固定、更新元素集合。论文提供作者代码链接，但本轮未运行该实现。
- [Dynamic Set Cover with Worst-Case Recourse，ICALP 2026](https://drops.dagstuhl.de/storage/00lipics/lipics-vol374-icalp2026/html/LIPIcs.ICALP.2026.153/LIPIcs.ICALP.2026.153.html)：阅读 §1.2 的主结果及鲁棒性定义。更新时间和解变化量的最坏情况控制已有明确理论路线，不能把减少重新求覆盖的工作量当作本项目独创。
- “Lazy and Eager Approaches for the Set Cover Problem”的作者 PDF URL 在本轮未返回可读正文；仅作为检索线索，没有据此陈述具体实验结果。

对本项目的判断：局部追加射线和缓存支持点首先是实现技术，不能单独支撑 MobiCom 新颖性。我们的覆盖关系会随射线位置、年龄、误差以及动作区域改变；这是对当前实现的观察，不是上述论文声称解决了这些物理问题。把现有动态集合覆盖理论移植到这里，需要明确输入更新模型、形成覆盖关系的成本与完整验证成本。平均编码更快也不能替代证据到期前的端到端准入验证。

本轮的新实验因此保留原始续期器作为配对对照，固定几何有效期和上游契约，直接检查连续续期、实际控制和失联回退。相关工作仍须进一步覆盖并公平实现，尚无新颖性成立结论。
